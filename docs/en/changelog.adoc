== Documentation change history

// Documentation revision (MAJOR.MINOR.REVISION). Format changes see CHANGELOG.adoc in the specification.
=== 2.0.0

* New documentation of the format `cz-ndic_d2-fcd-status` version 2.0 (DATEX II 3.7); replaces the
  documentation of the format cz-ndic_d2-fcd-v1.1 (DATEX II 2.3).
* Changes compared with version 1.1 (DATEX II 2.3):
** The format is converted to the DATEX II 3.7 model. The envelopes `d2LogicalModel` and `exchange` are not
   used; the root is `d2:payload`, the format is determined by the attributes `@profileName` and
   `@profileVersion`.
** Data quality and the number of vehicles are carried by native attributes of the model, not by the NDIC
   extension.
** Traffic status, level of traffic and queues are provided for all vehicles only; the NDIC extension
   contains no vehicle type. Speeds and travel times remain available also for cars and lorries.
** The start and end of a queue (`fromPoint`, `toPoint`) are given in per cent of the segment length
   (0–100, at most two decimal places).
** The NDIC extension has its own schema `cz-ndic_d2-fcd-extension-1.0.xsd`.
** Traffic status values of version 2 (`impossible`, `congested`, `heavy`) are not used by the 3.7 model in
   the same meaning. If no speed is available, `impossible` → `stationary`, `congested` → `queuing`,
   `heavy` → `slow`.
